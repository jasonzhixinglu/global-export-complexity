%% -------------------------------------------------------------- 2. The chain in stages
\sectionpage{2. The chain in stages}{2024 annual trade flows from the Trade Atlas. We estimate a matrix factor model to summarize trade flows by exporting and importing hubs.}

\textpage{The matrix factor model}{%
Per stage, the bilateral export matrix, $X$, has one row per exporter and one column per importer, such that cell $X_{ij}$ is the export value from $i$ to $j$ in 2024. The Matrix Factor Model (MFM) is given by
\[
  X = R\,F\,C' + e,
\]
for $N$ countries, $k$ export hubs and $r$ import hubs, with three pieces that
the stage charts draw as one column each:
\begin{itemize}\itemsep2pt
  \item $R$ ($N \times k$) are the \textbf{export loadings}: how much
        each exporting country participates in each export hub.
  \item $C$ ($N \times r$) are the \textbf{import loadings}, how much each importing country participates in each import hub.
  \item $F$ ($k \times r$) are the \textbf{matrix factors}: $F_{ab}$ is the dollar flow from export hub $a$ to import hub $b$.
  \item $e$ ($N \times N$) are the idiosyncratic errors.
\end{itemize}
A vector factor model summarizes co-movement in a vector of series as loadings
times a lower-dimensional vector of factors. The matrix factor model does the
same for a matrix, but needs two sets of loadings -- one for rows, one for
columns -- and the factors themselves form a lower-dimensional matrix. Setting
$k = r = 4$, each stage's whole trade matrix is summarized by 16 hub-to-hub
flows. Loadings are rotated to the basis that makes them non-negative, so a
loading reads as a share; the fit is close, with an R-squared of 0.95 to 0.99
across stages. Section 3 estimates the same model month by month, letting the
hubs move over time.}

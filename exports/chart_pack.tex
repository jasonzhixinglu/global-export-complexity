%% -------------------------------------------------------------- 2. The chain in stages
\sectionpage{2. The chain in stages}{2024 annual trade flows from the Trade Atlas. We estimate a matrix factor model to summarize trade flows by exporting and importing hubs.}

\textpage{The matrix factor model}{%
Per stage, the bilateral export matrix, $X$, has $i$-$j$th entry giving the export value from country $i$ to country $j$ in 2024. The Matrix Factor Model (MFM) for $X$ is given by
\[
  X = R\,F\,C' + e,
\]
for $N$ countries, $K$ export hubs indexed by $k$, and $M$ import hubs indexed by $m$:
\begin{itemize}\itemsep2pt
  \item $R$ ($N \times K$) are the \textbf{export loadings}: the weight of each country in each export hub.
  \item $C$ ($N \times M$) are the \textbf{import loadings}: the weight of each country in each import hub.
  \item $F$ ($K \times M$) are the \textbf{matrix factors}: $F_{km}$ is the dollar flow from export hub $k$ to import hub $m$.
  \item $e$ ($N \times N$) are the idiosyncratic errors.
\end{itemize}
}

\chartpage{The same model as a picture}{Similar to a PCA model, which summarizes co-movement in a vector as loadings times a low-dimensional vector of factors, the MFM does the same for a matrix: it summarizes $X$ by a low-dimensional matrix of factors with two sets of loadings.}{mfm_schematic.pdf}
